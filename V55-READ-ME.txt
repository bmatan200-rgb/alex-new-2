גרסה 55 — יציבות כניסה וניהול עסקים

שינויים:
- מסך הסופר אדמין ועמוד הכניסה שלו מופרדים ממסכי העסק וממנויי הנתונים שלו.
- שגיאת רשת זמנית בבדיקת משתמש אינה מבצעת יציאה מחשבון Firebase.
- קריאות מידע מנסות שוב לאחר תקלה זמנית. פעולות כתיבה ומחיקה אינן משוחזרות אוטומטית.
- רשימת העסקים והמסך הקיים נשמרים בזמן רענון נתונים ותקלה זמנית.
- טעינת פרטי עסק אינה מופעלת מחדש בגלל שינוי בפרמטר שאינו מזהה העסק.
- הוסר כפתור ניקוי היומן והלקוחות.
- השבתת עסק מחייבת סיסמת סופר אדמין ואישור באמצעות הקלדת מזהה העסק; המזהה נבדק גם בשרת.

התקנה ב-Render: העלאת הפרויקט, Build Command: npm ci && npm run build, Start Command: npm start.
